# Historical Design Archive

This directory is retained as source lineage and historical context only.

**Canonical design is in `../project-design/`.** Start at `../project-design/INDEX.md`.

The files here mix:

- older architecture versions (v2, v4.1),
- the v5 master narrative,
- delivery/tracker logs,
- aspirational plans,
- feature designs that are only partly or not implemented,
- raw session transcripts.

They are not current authority. Current behavior is defined by the code, the generated appendices under `project-design/appendices/`, and the implementation-aware parts under `project-design/parts/`.

Every historical file is mapped in `../project-design/appendices/design-source-map.md`. Known false or outdated claims are recorded in `../project-design/appendices/stale-claims-register.md`.

Do not add new normative design here. Add or update the relevant `project-design/parts/**` file and `project-design/TRACKER.md`.
